# 黄欣怡个人作品集网站（黑色交互版）

## 运行方式
解压后使用浏览器打开 `index.html` 即可预览，无需安装依赖。

## 文件说明
- `index.html`：主页、项目筛选、设计流程、个人介绍、联系页
- `project.html?id=0`：独立项目详情页（id 为 0–9）
- `projects.js`：项目名称、描述、图片路径
- `script.js`：项目分类筛选、滚动渐显和阅读进度交互
- `style.css`：黑底白字视觉样式与响应式布局
- `assets/`：项目图与个人介绍照片

## 交互功能
- 项目分类筛选
- 每个项目独立详情页，含项目说明、设计思考、空间表达和深化呈现
- 实验室改造项目提供拖动式改造前后对比
- 项目图片点击放大、上一个/下一个项目导航
- 滚动渐显、顶部阅读进度条、响应式移动端布局

实验室改造前对比图为用户提供的三张原始照片，保存为 `project-10/before-01.webp`、`before-02.webp`、`before-03.webp`；分别与对应的改造概念方案图进行滑块对比。

## 全站视觉升级（创意首页延展版）
- 项目详情页、设计流程、个人介绍与联系页统一采用黑色背景、白色文字。
- 延续首页的亮蓝、红色、荧光黄绿与少量紫色点缀，包含海报式背景字、悬停强调、卡片边框与按钮反馈。
- 项目详情页增加滚动阅读进度条与区块渐显，和首页滚动节奏保持一致。
- 保留项目图片统一 16:9 比例、分类筛选及实验室改造前后对比功能。
